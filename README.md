# 🌟 Chill-Store — Modern E-Commerce Platform

Chill-Store is a sleek and responsive **full-stack e-commerce application** designed to provide a smooth shopping experience to users and an intuitive dashboard for sellers.  
It includes product listings, image uploads, order handling, and secure payments via **eSewa**.

---

## 🔧 Tech Stack

### **Frontend**
- ⚛️ React.js  
- 🎨 Tailwind CSS  
- 🔄 Recoil  
- ⚡ Vite  

### **Backend**
- 🟢 Node.js  
- 🚂 Express.js  
- 🗄️ MongoDB + Mongoose  
- 🖼️ Multer (Image Upload)  

### **Payments**
- 💸 eSewa Payment Gateway

## 🚀 Features

### 🛍️ **User Features**
- Product browsing & filtering  
- Add to cart & checkout  
- eSewa online payment  
- Order status tracking  
- Responsive UI  
- Profile management  

### 🧑‍💼 **Seller Features**
- Add, edit & remove products  
- Product image upload via Multer  
- Seller dashboard with charts  
- View & manage orders  
- Earnings visualization
